# VEXELON native Godot client

See [GODOT.md](../GODOT.md) for current run/input instructions and [the Neo-Vector guide](../docs/NEO_VECTOR_STYLE_GUIDE.md) for canonical presentation.

The native client uses the shared authoritative Node server for competitive gameplay and a loopback helper for offline training. It now uses a black background, restrained mode-specific HUD, progressive Tutorial, Practice tools in Pause, compact targeting controls and one canonical palette. Audio/music/accessibility remain in Settings; no player-selectable theme or light mode exists.

Physical controller families, standalone offline export packaging and long listening sessions remain unverified. See [UI delivery report](../docs/UI_UX_SIMPLIFICATION.md).
