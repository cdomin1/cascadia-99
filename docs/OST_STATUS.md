# Soundtrack status — external recordings only

**Current soundtrack: zero installed tracks. SFX-only gameplay is intentional.**

All Codex-generated compositions, procedural music sequencers, generated bass/drum patterns, compiled scores, preview recordings and music render/composition tools are retired. No replacement composition, MIDI, placeholder recording or synthesized fallback is supplied. Historical Git commits retain earlier work; they are not the current soundtrack specification.

The developer will supply properly licensed external music. Codex handles playback, mixing and integration, not music composition. There is no adaptive-music implementation pending track selection. Short existing gameplay/UI event sounds, including countdown, chains, Overdrive and victory/defeat cues, remain SFX.

See [music imports](MUSIC_IMPORTS.md) for the shared empty registry, supported formats, credit fields, synchronization and playback limitations. See [audio engineering](AUDIO_OVERHAUL.md) for retained mixing and validation.
