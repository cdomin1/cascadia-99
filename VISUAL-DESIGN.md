# VEXELON presentation

The canonical specification is [Neo-Vector Arcade](docs/NEO_VECTOR_STYLE_GUIDE.md): “1982, BUT IMPOSSIBLE.”

Black is the playfield. Light is information. The board is the hero. One semantic palette, original geometric tiles and readable selector replace historical selectable themes and pixel-art final direction. Title uses progressive disclosure; gameplay HUD is contextual; Tutorial teaches one system at a time; Practice tools belong in Pause.

Historical artwork is retained where useful; it must not restore retired theme infrastructure. See [UI/UX delivery](docs/UI_UX_SIMPLIFICATION.md) for changes and verification.
