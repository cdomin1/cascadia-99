# Kode Mono

Unmodified variable font (weight 400–700), obtained from the official Google Fonts distribution on 2026-10-07:
https://github.com/google/fonts/tree/main/ofl/kodemono

Typeface upstream: https://github.com/isaozler/kode-mono
License: SIL Open Font License 1.1, included as OFL.txt.
The identical native copy lives at godot/assets/fonts/kode-mono/.
No runtime Google Fonts/CDN request is used. Native variations select 400/500/700 with system fallback for unsupported glyphs; browser uses a monospace fallback.
